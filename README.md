# 外卖红包快捷指令配置

配置地址：
https://raw.githubusercontent.com/2629728088/waimai-shortcuts/main/shortcut2026.json

将原快捷指令第一个“URL”动作中的远程 JSON 地址替换为上面的地址；后续继续读取 `meituan` 字段。

- `meituan` / `meituan_waimai`：同一美团外卖红包入口的 App Scheme。
- 美团短链：http://dpurl.cn/oB2dwr7z
- 此链接由当前美团联盟业务登录态调用原生批量转链接口生成，业务返回成功；佣金归属及到账仍需联盟订单核对。
- 仅打开领券入口，不代表红包已经领取成功；优惠和资格以美团显示为准。
- 活动及短链不保证永久有效。需要更换入口时更新 JSON，手机无需重新替换配置地址。
- 未添加未验证的淘宝、饿了么或其他平台链接，避免继续使用他人的推广链接。
- 仓库只放公开跳转链接，不放 token、Cookie、密码或 API 密钥。

## 原快捷指令的日期记录注意事项
原指令读取“外卖红包/美团.txt”，但部分写入动作使用“美团. txt”（含空格）或“饿了么.txt”。建议在手机上统一为“外卖红包/美团.txt”；仅更换远程配置地址不会修复这些本地动作。
